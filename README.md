# The White Meat

A listening crate. Pick an artist, work through every album, EP, and non-album single, and keep the songs that matter (the white meat). Artists you will not listen through go in Sucks.

This is a rebuild of the grok.me app after that workshop was wiped. Your catalog lives in this browser only until you download a backup.

## Open it

If someone sent you a link, use that.

On this computer, open `index.html` in a browser, or ask The White Meat bot to start it for you.

## Restore your old crate

1. Open **Settings**
2. Click **Restore backup**
3. Choose the `the-white-meat-….json` file you downloaded from grok.me

That file works here. Same format.

## Backup

**Settings → Download backup** saves a JSON file. Keep a copy somewhere safe. You can restore it later, including on another computer.

## What it does

- **Artists** — add or import a discography (`1997-OK Computer` lines)
- **Genre** — set a genre on an artist; it covers every release and meat
- **White Meat** — the keepers
- **Sucks** — artists you will not work through
- **Settings** — backup and restore

No account. No Spotify. No cloud sync except the JSON file you download.
